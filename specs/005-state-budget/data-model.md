# 数据模型：任务状态与预算

## StepRecord

一个不可变的历史条目，包含从 1 开始计数的步号、所选动作以及可选的结果快照。

## TaskState

一个不可变的任务快照，包含：

- `goal`：非空且已归一化的目标文本。
- `step`：非负的已完成步数。
- `context`：由应用提供的 JSON 兼容状态。
- `history`：有序的不可变步骤记录。
- `last_result`：来自最新步骤的可选 JSON 兼容结果。

`advance(action, result)` 返回一个新状态，其中 `step + 1`、包含一条新历史记录，并带有新的最新结果。它不修改源状态，也不修改调用方拥有的嵌套值。

## ExecutionBudget

一对不可变的步数与模型调用上限及其剩余计数。每次消耗操作返回一个新预算，并将其中一个剩余计数减一。剩余计数为零时拒绝消耗。上限与剩余值都是有限的非负整数，且剩余值不大于其对应的上限。
